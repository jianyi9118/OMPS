# OMPS 单位综合管理平台

PHP + MariaDB 内部管理系统，在单位现有的 **XAMPP 7.2.3** 上运行，不安装任何额外的包、不使用 Composer、不使用第三方框架（PHP 内核和前端都是自己写的）。

- 设计文档：`docs/` 与设计评审稿（v0.31 起包含兼容范围和验收清单）
- 当前进度：
  - **第一阶段（基础框架）**：登录与会话、用户与角色权限、部门与人员基础信息、多语言、操作 / 审计 / 登录日志、命令行工具与自动测试
  - **第二阶段（人员档案）**：完整档案（学历、工作经历、职称、成果、家属）、证件号加密、本人修改与审核、照片和附件、批量导入导出
  - **第三阶段（计划）**：长期到日计划树、多人协同分配、我的任务、计划与业绩树、时间显示、占比提示
  - **第四阶段（业绩与报告）**：写业绩（草稿、提交、撤回、附件）、业绩审核（通过、修改并通过、批量通过、退回）、完成百分比逐级汇总、综合报告（按条件生成、报告列表、版本、打印、Word / Excel 下载、手动报告和报告文档）
  - **第七阶段（自定义与数据统计）**：自定义字段（人员档案、设备档案、计划；表单、详情、列表、搜索、导出、统计）、数据统计（人员统计、部门统计、自定义统计，按权限范围；打印、Excel）、统计页面设计、系统主题（主色调、菜单和顶部栏样式、浅色 / 深色、Logo）、登录页图片
  - **按角色的工作台**：单位负责人（各部门情况、单位重点计划）、部门负责人（本部门成员、本部门计划）、超级管理员另有系统状态（最近备份、在线用户、定时任务、缺失翻译）；普通成员直接进入“我的任务”；全系统统一的“滞后”规则（落后时间进度 10 个百分点以上）
  - **第九阶段（文件、菜单、语言、备份）**：文件管理（按平台目录浏览、预览、下载、删除自己的文件、回收站 30 天内恢复、重复文件合并为引用；计划改名时附件文件夹随之改名）；菜单管理（按语言改名、调整顺序、隐藏）；多语言管理（语言列表、完成度、逐条翻译、Excel 导出导入，100% 才能启用，可新增语言）；数据备份（数据库 + 文件、每日自动、升级前自动、保留天数、下载、恢复需密码，`php omps backup:create / backup:restore`）
  - **第八阶段（文档模板）**：综合报告和人员登记表的 Word 内置版式（公文式报告、带照片的登记表）；超级管理员可上传自己的 Word 模板（写 `{{占位符}}`，任一语言的名称都可以；表格行按记录重复；示例模板下载、试生成、占位符检查、切换使用的模板）；人员档案抽屉“登记表”按钮（只含查看人有权看到的内容，查看他人记审计日志）
  - **第六阶段（设备管理）**：设备档案（部件及更换历史、许可证及到期提醒、使用人历史、附件、Excel 导入导出）、使用与监测（使用记录、硬件异常、采集客户端、采集范围）、故障与维修（报修、派修、完成维修、维修记录），工作台人人可报修；采集客户端在 `collector/`（Windows 自带 PowerShell 即可运行）
  - **第五阶段（我的事务与提醒）**：铃铛与我的通知、待办事项、记事本（提交上级、批示）、下发事项（提示 / 文档 / 指令、完成并回复、催办、撤回）、提醒引擎（`php omps schedule:run`）和提醒规则、个人提醒偏好、页面顶部督促条、跳转定位

## 兼容范围

| 项目 | 最低（单位现有） | 已验证 |
|---|---|---|
| PHP | 7.2.3 | 7.2.3、8.2.36、8.4.28 |
| 数据库 | MariaDB 10.1.31 | MariaDB 10.1.31、10.4 |
| Web 服务器 | Apache 2.4（XAMPP 自带） | 有 / 无 mod_rewrite 都可以 |

编码规则见 `docs/CODING_RULES.md`。每次修改后在两套环境运行 `php omps compat:check`、`php omps i18n:check`、`php omps test`。

## 目录

```
app/        内核 Core、数据库 Database、中间件 Middleware、引擎 Engines、业务模块 Modules、命令行 Console
config/     配置（从 .env 读取）
database/   migrations（建表）、seeds（基础数据，不含任何账号密码）
public/     唯一对外目录（Apache 文档根目录）：index.php、assets
resources/  视图、语言包（zh-CN、en-US）
storage/    日志、上传、备份（不可通过 URL 访问）
tests/      自动测试
collector/  设备采集客户端（PowerShell 脚本和安装文件，不在网站目录中，由设备管理员在页面上下载）
omps        命令行入口
```

安装步骤见 `docs/INSTALL.md`。
