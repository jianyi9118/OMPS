OMPS 设备采集客户端 1.0
========================

用途
  由单位统一安装在登记过的电脑上，定期把这台电脑的硬件信息报给 OMPS，
  用来核对设备档案中的部件（CPU、内存、硬盘等）是否被更换。

上报什么（只上报设备管理员在“采集范围”中勾选的项目）
  计算机名、操作系统版本、CPU、内存、硬盘、主板、显示器、网卡（型号、序列号、容量）。
  设备详情页和“使用与监测 - 采集范围”公开显示当前的采集范围。

不上报什么
  键盘输入、屏幕内容、文件、浏览记录、聊天、登录账号和密码。
  采集脚本是明文的 omps-collector.ps1，任何人都可以打开查看。
  运行 powershell -ExecutionPolicy Bypass -File omps-collector.ps1 -Show
  可以看到本机将要上报的全部内容（不会发送）。

什么时候上报
  开机 5 分钟后一次，每天 10:00 一次（Windows 任务计划，名称以 OMPS Collector 开头）。

安装
  1. 设备管理员在 OMPS 设备档案中打开这台设备，“采集”标签里点“生成注册码”（7 天内有效，只能用一次）。
  2. 在这台电脑上右键 install.cmd，选择“以管理员身份运行”，输入服务器地址和注册码。

卸载
  右键 uninstall.cmd，选择“以管理员身份运行”；再请设备管理员在“采集客户端”中撤销本机。

要求
  Windows 7 及以上，自带的 PowerShell 2.0 即可，不需要安装其他软件。
